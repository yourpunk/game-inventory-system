Relational Model
Player(nickname, login, level, experience, gold)
Pet(name, race, player)
FK: (player) ⊆ Player(nickname)
Ability(name, ability)
FK: (name) ⊆ Pet(name)
Inventory(nickname, number, capacity)
FK: (nickname) ⊆ Player(nickname)
Item(item_name, type, cost, rarity, power, stamina, defense,
nickname, number)
FK: (nickname, number) ⊆ Inventory(nickname, number)
Transaction(server, time, player, item)
FK: (player) ⊆ Player(nickname)
FK: (item) ⊆ Item(item_name)
Buying(server, time, fee)
FK: (server, time) ⊆ Transaction(server, time)
Selling(server, time, merchant_cut)
FK: (server, time) ⊆ Transaction(server, time)
Combines_with(base_item, component_item)
FK: (base_item) ⊆ Item(item_name)
FK: (component_item) ⊆ Item(item_name)
